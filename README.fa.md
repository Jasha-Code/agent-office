# 🏢 دفتر کار ایجنت‌ها (Agent Office)

**یک دفتر کار ۳ بعدی و چندنفره کارتونی که تیم شما آن را با دستیارهای هوش مصنوعی به اشتراک می‌گذارد.**

دستیارهای هوشمند **Claude Code**، **Codex**، **OpenCode**، **Grok**، **Muse**، **DeepSeek Harness** و **Cursor** را پشت میزها بنشانید، ترمینال زنده هر یک را روی لپ‌تاپ مقابلش تماشا کنید، و در کنار هم وارد هر کدام شوید. هر مخزن گیت‌هاب یک طبقه از ساختمان است!

## 🌟 دفتر کار ایجنت‌ها چیست؟

- **یک طبقه به ازای هر پروژه:** سوار آسانسور شوید، یکی از مخازن گیت‌هاب خود را انتخاب کنید؛ دفتر کار آن را کلون کرده و یک طبقه اختصاصی برای آن باز می‌کند. تمام کارمندان، تخته‌ها و صف وظایف آن طبقه روی همان مخزن کار می‌کنند.
- **دستیارهای هوش مصنوعی پشت میزها:** جلوی یک میز خالی بروید، کلید **E** را بزنید و دستیار مورد نظر خود را (کلود، کدکس، اوپن‌کد، گروک، میوز، دیپ‌سیک یا کرسر) به همراه مدل و سطح تفکر/استدلال انتخاب کنید. ترمینال زنده دستیار روی لپ‌تاپ ظاهر می‌شود و هر کسی در تیم می‌تواند آن را باز کرده و تایپ کند.
- **دستور صوتی به‌جای تایپ کردن:** در ترمینال یا کادر درخواست، کلیدهای **Ctrl+Space** (یا دکمه **🎤**) را نگه‌دارید و صحبت کنید؛ صدای شما به متن تبدیل شده و برای ارسال آماده می‌شود. پردازش توسط مرورگر انجام می‌شود و نیازی به نصب ابزار اضافه نیست.
- **اعلان‌ها و باخبر شدن از وضعیت:** دستیاری که برای پاسخ به سوال یا دریافت مجوز متوقف می‌شود، یک چراغ قرمز بالای میزش روشن می‌کند، بنری در بالای صفحه با نام و موضوع سوال نمایش می‌دهد و زنگ هشدار به صدا درمی‌آورد. کارمندی که کارش تمام شده، بالا و پایین می‌پرد. با زدن کلید **N** مستقیماً به سراغ کارمندی می‌روید که منتظر شماست.
- **دسترسی از طریق موبایل و سیستم‌های سبک:** مسیر `/lite` نسخه ۲ بعدی دفتر است: تمام کارمندان و وضعیت آن‌ها، ترمینال با کلیدهای میانبر موبایل و تخته‌های پروژه بدون نیاز به رندر سه‌بعدی سنگین در دسترس هستند.
- **تخته‌های گیت‌هاب روی دیوارها:** مسائل (Issues) و درخواست‌های ادغام (PRs) روی تخته‌های چوب‌پنبه‌ای نصب هستند. می‌توانید یک مسئله را بردارید و به یک کارمند بسپارید، یا وظایف را در صف کارها بگذارید.
- **همکاری تیمی:** گفتگوی صوتی زنده (Voice)، چت متنی، اشتراک‌گذاری صفحه نمایش روی تلویزیون لابی و تخته وایت‌برد مشترک برای طراحی و کشیدن دیاگرام به صورت زنده.
- **فضای تفریحی و استراحت:** دستگاه بازی آرکید BLOCKFALL در لابی، حلقه بسکتبال، سگ دوست‌داشتنی دفتر که می‌توانید نوازشش کنید، خودروهای اسپرت فراری و لامبورگینی در گاراژ برای رانندگی در پیست، کافه پشت‌بام با دی‌جی، تخته دارت و پرتاب تبر!

## 🇮🇷 پشتیبانی از زبان فارسی و RTL

این پروژه مجهز به سیستم بومی‌سازی دو زبانه با پیش‌فرض فارسی است:
- **جهت راست‌به‌چپ (RTL):** تمام پنل‌ها، پنجره‌ها، نوار ابزار، داک بالا و منوها به‌صورت خودکار با ساختار RTL تطبیق یافته‌اند.
- **تایپوگرافی زیبا با فونت وزیرمتن (Vazirmatn):** متون با فونت خوانا و استاندارد فارسی نمایش داده می‌شوند.
- **امکان تغییر زبان:** از طریق منوی **☰ ← ⚙️ تنظیمات (Settings) ← شخصی شما (You) ← زبان / Language** می‌توانید در هر زمان بین زبان فارسی و انگلیسی جابجا شوید.

## 🚀 راهنمای اجرای محلی

### پیش‌نیازها
- **Node.js نسخه 20 یا بالاتر**
- **Git**
- دست‌کم یکی از CLIهای هوش مصنوعی نصب و واردشده باشد: `claude`, `codex`, `opencode`, `grok`, `muse`, `dsh` یا `cursor-agent`.

### مراحل اجرا
```bash
# ۱. کلون کردن مخزن
git clone https://github.com/Jasha-Code/agent-office.git
cd agent-office

# ۲. نصب وابستگی‌ها و بیلد اولیه
npm ci

# ۳. اجرای محیط توسعه
npm run dev
```

دفتر کار روی آدرس `http://localhost:5173` باز خواهد شد.

همچنین برای اجرای نسخه کامل سرور محلی:
```bash
npm run build
npm start
```

## 🎮 راهنمای کلیدها و کنترل‌ها

| کلید / نماد | عملکرد |
| :--- | :--- |
| **W A S D** | حرکت و راه رفتن (نگه‌داشتن Shift برای دویدن) |
| **Space** | پریدن |
| **Mouse (موس)** | دید به اطراف در حالت اول شخص (کلیک برای گرفتن موس، Esc برای آزادسازی) |
| **E یا کلیک** | تعامل با شیء روبرو: استخدام، باز کردن ترمینال، خواندن تخته، نشستن، رانندگی و... |
| **N** | رفتن مستقیم به کارمند بعدی که منتظر پاسخ است یا کارش پایان یافته |
| **P** | ارسال درخواست / پرامپت به دستیار پشت میز روبرو |
| **C** | مشاهده فایل‌های تغییریافته و Diff کد، کامیت و ایجاد PR |
| **B** | باز کردن شل و ترمینال مستقل در میز خالی (برای اجرای دستورات لینوکس، سرور و تست) |
| **R** | بیدار کردن کارمند به خواب رفته |
| **X** | پایان کار و ترخیص کارمند (تخلیه میز) |
| **L** | نصب یا تغییر تابلوی عنوان بالای میز (مانند "عملیات"، "توسعه فرانت‌اند") |
| **F** | نصب تصویر دلخواه از اینترنت روی دیوارهای دفتر |
| **Q** | بازگرداندن کارت تسک به دست گرفته شده یا انداختن توپ بسکتبال |
| **O** | باز کردن درخواست ادغام (PR) شاخه کارمند |
| **T** | باز کردن کادر گفتگوی متنی (Chat) |
| **G یا ۱ تا ۶** | اجرای شکلک‌ها و انیمیشن‌ها: دست تکان دادن، تشویق، لایک، رقص، اشاره و... |
| **/** | جستجو در تاریخچه گفتگوها و تمامی ترمینال‌های حاضر در طبقه |
| **Ctrl+K** | پالت دستورات: جستجوی سریع کارمندان، وظایف، سرویس‌ها یا همکاران |
| **V** | ورود به گفتگوی صوتی / مکالمه با نگه‌داشتن کلید (Push to Talk) |
| **M** | قطع یا وصل صدای میکروفون در مکالمه صوتی |
| **Ctrl+Space** | تایپ صوتی با میکروفون در کادر پرامپت یا ترمینال |
| **Tab** | باز کردن منوی اصلی (☰) شامل تمامی ابزارها و پنجره‌ها |
| **Esc** | بستن هر پنجره و بازگشت به نمای دفتر |
| **☕** | نوشیدن قهوه در آشپزخانه برای افزایش موقت سرعت حرکت و ارتفاع پرش |
| **🐶** | نوازش سگ دفتر (وقتی کارمندی منتظر است، سگ به سمت میزش می‌دود و پارس می‌کند) |

## 🧱 ساختار فنی پروژه

- **بخش کلاینت سه‌بعدی (`src/client/`):** توسعه داده‌شده با Three.js، Vite و تایپ‌اسکریپت، بدون فریم‌ورک‌های سنگین فرانت‌اند برای دستیابی به بالاترین نرخ فریم (FPS).
- **بخش کلاینت دوبعدی (`src/client/lite.ts`):** بدون وابستگی به Three.js، ایده‌آل برای دستگاه‌های ضعیف یا تلفن‌های همراه.
- **بخش سرور (`src/server/`):** سرور نودجی‌اس با وب‌سوکت برای همگام‌سازی وضعیت چندنفره، مدیریت ترمینال‌های PTY و ادغام با git worktree.
- **سیستم بومی‌سازی (`src/client/ui/i18n.ts`):** مدیریت زبان‌های فارسی و انگلیسی همراه با تغییر جهت خودکار صفحه، بدون تاثیر بر تست‌های متنی داخلی و قوانین اندازه کد (`tests/size.test.ts`).
